브라우저에서 바로 돌아가는 테트리스. 빌드 도구도, 의존성도 없다. HTML·CSS·JS 세 파일이 전부다.

**플레이 →** https://harryfoto.github.io/classic-tetris/

## 조작

| 동작 | 키 |
| --- | --- |
| 이동 | `←` `→` |
| 소프트 드롭 | `↓` |
| 하드 드롭 | `Space` |
| 시계 회전 | `↑` 또는 `X` |
| 반시계 회전 | `Z` |
| 홀드 | `C` |
| 일시정지 | `P` |
| 시작 / 재개 | `Enter` |

모바일에서는 화면 아래 터치 버튼을 쓴다. 좌우와 아래 버튼은 누르고 있으면 계속 움직인다.

## 구현한 것

- **7-bag 랜덤** — 일곱 종류가 한 번씩 나온 뒤 다음 묶음으로 넘어간다. 같은 조각이 연달아 쏟아지지 않는다.
- **고스트 피스** — 지금 하드 드롭하면 떨어질 자리를 반투명하게 표시한다.
- **홀드** — 조각 하나를 보관했다가 나중에 꺼낸다. 꺼낸 직후에는 다시 보관할 수 없다.
- **다음 조각 3개 미리보기**
- **락 딜레이** — 바닥에 닿아도 420ms 동안은 밀거나 돌릴 수 있다.
- **DAS / ARR** — 키를 누르고 150ms 뒤부터 40ms 간격으로 자동 이동한다. OS 키 반복에 맡기지 않는다.
- **벽 킥 · 바닥 킥** — 회전할 자리가 막혀 있으면 좌우와 위로 밀어보고 가능한 위치를 찾는다.
- **최고 점수 저장** — `localStorage`에 남는다.
- **BGM과 효과음** — 음원 파일 없이 Web Audio API로 직접 합성한다.

## 점수

| 한 번에 지운 줄 | 점수 |
| --- | --- |
| 1 | 100 × 레벨 |
| 2 | 300 × 레벨 |
| 3 | 500 × 레벨 |
| 4 | 800 × 레벨 |

소프트 드롭은 한 칸당 1점, 하드 드롭은 한 칸당 2점. 10줄마다 레벨이 오르고 낙하 속도가 15%씩 빨라진다.

## 실행

정적 파일이라 그냥 열어도 되지만, 로컬 서버로 띄우는 쪽이 안전하다.

```bash
git clone https://github.com/harryfoto/classic-tetris.git
cd classic-tetris
python3 -m http.server 8000
```

`http://localhost:8000` 으로 접속한다.
